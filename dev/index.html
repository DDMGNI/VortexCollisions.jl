VortexCollisions

Documentation for VortexCollisions.

Evaluation of collision operators for the vorticity equation. The package provides a two-dimensional Fourier grid, the transforms and spectral operators on it, quadrature rules, and the Fokker–Planck collision operator built from them.

Set JULIA_NUM_THREADS to more than one to run a simulation in parallel.
